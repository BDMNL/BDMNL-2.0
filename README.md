# BDMNL-2.0
Nieuwe BDMNL 2.0 website en SEO rebuild

## SEO city landing pages

This repository includes a reusable static landing page template for local SEO pages.

- Shared styles: `assets/css/landing.css`
- Reusable template: `templates/city-landing-template.html`
- City content and metadata: `data/city-pages.json`
- Generator: `scripts/generate-city-pages.py`

Generate or refresh all city pages:

```bash
python3 scripts/generate-city-pages.py
```

Generated pages:

- `website-laten-maken-brielle/`
- `website-laten-maken-hellevoetsluis/`
- `website-laten-maken-rockanje/`
- `website-laten-maken-spijkenisse/`
- `website-laten-maken-rotterdam/`
